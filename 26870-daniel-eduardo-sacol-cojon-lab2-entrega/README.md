## Descripción
Programa para la gestión de Escenarios y Artistas de un Festival, en el que se maneja con un array estatico los escenarios y uno dinamico los artistas. Se incluye un CRUD para cada caso con manejo de excepciones típicas y un reporte estadistico del festival. Se desarrolló usando un patrón de diseño MVC.

## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
