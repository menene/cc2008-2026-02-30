
# Laboratorio 2 - Arreglos y Excepciones

**Nombre completo:** Manuel Alexander Tziboy Catún y Juan Fernando Santos Mérida
**Carné:** 26085 y 26693

## Descripción

Sistema desarrollado en Java para gestionar un Festival Universitario de Música, aplicando conceptos de programación orientada a objetos. Permite administrar escenarios mediante arreglos y artistas mediante ArrayList, realizando operaciones de registro, consulta, modificación y eliminación. Además, incorpora validación de datos y manejo de excepciones con try-catch y finally para garantizar una ejecución controlada ante entradas inválidas.

## Cómo ejecutar

```bash
javac -d bin src/*.java
java -cp bin Main
```
