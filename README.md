#Ejercicio 3 - Sistema de Control de Órdenes de Servicio de un Taller Automotriz

**Nombre completo:** Laura Suseth Morales Murga  
**Carné:** 26281

##Descripción

Programa desarrollado en Java para administrar las órdenes de servicio de un taller automotriz. El sistema permite registrar, consultar, buscar, modificar y cancelar órdenes de servicio utilizando una colección dinámica mediante `List` y `ArrayList`.

También permite consultar órdenes por placa, calcular el costo total y promedio, identificar la orden con mayor costo y consultar la cantidad de órdenes registradas. El programa utiliza el patrón Modelo-Vista-Controlador (MVC), encapsulamiento y manejo de excepciones mediante `try-catch` y `finally`.

## Cómo ejecutar

```bash
javac -d bin src/*.java
java -cp bin Main
```
