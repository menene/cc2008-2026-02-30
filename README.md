# Ejercicio 3 - Sistema de Control de Órdenes de Servicio de un Taller Automotriz

**Nombre completo:** Emmanuel Alejandro Montufar Pinto
**Carné:** 26805

## Descripción

Programa para registrar, consultar, buscar, modificar y cancelar órdenes de servicio de un taller automotriz. El sistema utiliza las clases OrdenServicio, Taller, Vista, Controlador y Main. Las órdenes se almacenan dinámicamente mediante List y ArrayList, y los errores de entrada y las órdenes inexistentes se controlan utilizando excepciones.

## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
