# Ejercicio 3 - Sistema de Control de Órdenes de Servicio de un Taller Automotriz

**Nombre completo:** Emily Lucila Menchú Menchú
**Carné:** 20472

## Descripción
Este programa gestiona las órdenes de servicio que llegan a un taller. Ayuda a mantener el registro de las órdenes, agrega nuevas, modifica y cancela órdenes usando listas dinámicas (ArrayList).
También lanza y maneja excepciones por si surgen excepciones.

## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
