Laboratorio 2 - Arreglos dinámicos
Nombre completo: Edith Estefany Pérez Trujillo Carné: 26952

Descripción
Explicación de la tarea: Este laboratorio resuelve el problema de administracion de escenarios y artistas de un festival de musica universitario por medio de distintas acciones como el registro, modificacion, eliminacion, consultas de los arreglos y consultas individuales tanto de escenarios como de artistas. También se incluye el reporte general del festival.  Se compone de las clases Main, Controlador, Vista, Festival, Escenario y Artista. Festival es quien recibe el arreglo de escenarios de maximo 5 escenarios  y el ArrayList de artistas. Se pensó en evitar que el programa "muera" de repente a causa de errores del usuario. 

Cómo ejecutar
javac -d bin src/*.java
java -cp bin Main
