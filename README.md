**Nombre Completo:** María del Pilar Ordóñez Helton
**Carné:** 26360

## Descripción
El programa busca administrar un festival universitario de música, permitiendo registrar el festival, sus escenarios y los artistas que participarán. Está compuesto por las clases Main, Controlador, Vista, Festival, Escenario y Artista. Como decisión de diseño, se utiliza un arreglo de 5 posiciones para los escenarios y un ArrayList para los artistas, ya que la cantidad de artistas puede cambiar. También se utilizan excepciones para controlar datos inválidos y errores al ingresar información.


## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
