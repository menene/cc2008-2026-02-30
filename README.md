## Descripción

Este programa permite llevar el control de las órdenes de servicio de un taller automotriz. Se pueden agregar, buscar, modificar y eliminar órdenes. También permite buscar órdenes por placa, calcular el costo total y promedio, y encontrar la orden con el costo más alto.

Para almacenar las órdenes se utiliza una colección dinámica ArrayList.

## Compilar el programa

javac -d bin src/*.java

## Ejecutar el programa

java -cp bin Main
