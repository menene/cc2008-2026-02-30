# Ejercicio 3 - Arreglos dinámicos

**Nombre completo:** Edith Estefany Pérez Trujillo
**Carné:** 26952

## Descripción
Explicación de la tarea: Este ejercicio resuelve el problema de un taller automótriz y la gestión de sus órdenes, lo componen las clases Main, Controlador, Vista y Orden ya que por medio de controlador se maneja el ArrayList de Orden donde se almacena cada orden segun se registre. Al igaul, se creo otro arraylist que almacenará las ordenes con coincidencia en la misma placa. Se pensó también en evitar posibles errores del usuario con el objetivo de no cortar el programa de repente. 

## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
