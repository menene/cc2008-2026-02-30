# Laboratorio 2 - Festival Universitario de Música

**Nombre completo:** Arnoldo Caleb Carias Donis  
**Carné:** 261937

## Descripción

Este programa permite administrar un festival universitario de música. Utiliza un arreglo básico de cinco posiciones para almacenar escenarios y un ArrayList para registrar artistas. También permite realizar búsquedas, modificaciones, eliminaciones y generar un reporte general.

El programa está compuesto por las clases Escenario, Artista, Festival y Main.

## Cómo ejecutar

    javac -d bin src/*.java
    java -cp bin Main
