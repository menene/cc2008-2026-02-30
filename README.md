# Arreglos dinámicos, Arraylist, List y Excepciones

**Nombre completo:** Jared Eduardo Guerra Aguirre 
**Carné:** 26502

## Descripción

Este programa permite administrar las órdenes de servicio de un taller automotriz. Permite registrar, consultar, buscar, modificar y cancelar órdenes de servicio.

También permite consultar órdenes por placa, calcular el costo total y promedio de los servicios, identificar la orden de mayor costo y mostrar la cantidad de órdenes registradas.

El programa utiliza clases, objetos, encapsulamiento, ArrayList y manejo de excepciones.

## Cómo ejecutar

```bash
javac -d bin src/*.java
java -cp bin Main
```
