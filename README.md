## Descripción

Programa desarrollado en Java para administrar un Festival Universitario de Música. Permite gestionar los escenarios y artistas participantes utilizando un arreglo básico y un `ArrayList`, además de aplicar manejo de excepciones para controlar entradas y operaciones inválidas.

## Cómo compilar y ejecutar

Desde la carpeta raíz del proyecto:

```bash
javac -d bin src/*.java
java -cp bin Main
```

## Estructura

- `src/`: código fuente del programa.
- `bin/`: archivos compilados.
- `docs/`: análisis y diagrama UML.
