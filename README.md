## Descripción
El problema que resuelve este programa es la administración de los escenarios y artistas de un festival universitario. Está compuesto por las clases: Main, Vista, Controlador, Festival, Escenario y Artista, siguiendo el modelo MVC. Utilicé un array básico de 5 posiciones para almacenar los escenarios, luego un array dinámico para almacenar a los artistas y por último use excepciones para manejar datos incorrectos y hacer que el programa no muera.

## Cómo ejecutar
```bash
javac -d bin src/*.java
java -cp bin Main
```
