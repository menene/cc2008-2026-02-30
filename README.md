## Descripción

Este programa permite administrar un festival universitario de música. Permite configurar, consultar, modificar y retirar los escenarios disponibles para el festival.

También permite registrar, consultar, buscar, modificar y cancelar la participación de artistas, y generar un reporte con información sobre los escenarios y artistas registrados.

El programa utiliza un arreglo básico para almacenar los escenarios, un ArrayList para administrar los artistas y manejo de excepciones para controlar entradas incorrectas y valores inválidos.

## Cómo ejecutar

```bash
javac -d bin src/*.java
java -cp bin Main
```
